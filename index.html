Letterboxd Random Picker — Privacy Policy

Last updated: 2026-07-30

Letterboxd Random Picker is a Chrome extension that picks a random film from a Letterboxd list or watchlist you're viewing. This page explains what the extension does and does not do with your data.

What the extension does

When you click the "Pick a movie" button on a Letterboxd list or watchlist page, the extension reads film titles and links that are already present in that page's HTML. If the list spans multiple pages, it may load those additional pages directly from letterboxd.com to build the full list before picking one at random.

What the extension does not do

  • It does not collect, store, or transmit any personal data.
  • It does not send any data to servers other than letterboxd.com itself, and only to load additional pages of the same list you're already viewing.
  • It does not use analytics, tracking, or advertising services.
  • It does not read or interact with any site other than Letterboxd.
  • It does not require you to sign in or create an account.

Data storage

The extension does not persist any data to disk or browser storage. All scraped film data lives only in the page's memory while it's open and is discarded when you navigate away or close the tab.

Source code

This extension is open source. You can review the full source code on GitHub.

Questions

If you have questions about this policy, please open an issue on the GitHub repository.

Letterboxd Random Picker is not affiliated with or endorsed by Letterboxd.
